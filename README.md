# ClearLedger Consulting

Professional accounting and financial consultancy web application.

## Overview

ClearLedger is a modern, responsive website for an accounting and financial consultancy business. It provides a professional online presence with service listings, pricing tiers, client testimonials, a client portal overview, and a consultation booking form.

## Features

- **Responsive Design** - Fully mobile-friendly, works on all screen sizes
- **Service Showcase** - Six detailed service offerings (Bookkeeping, Tax Planning, Financial Advisory, Audit & Assurance, Business Consulting, Payroll)
- **Pricing Tiers** - Three transparent pricing plans (Starter, Professional, Enterprise)
- **Client Testimonials** - Social proof section with client reviews
- **Client Portal Preview** - Highlights secure document upload, real-time dashboard, consultation booking, and bank-level security
- **Contact & Booking Form** - Form with validation for booking free consultations
- **Animated Statistics** - Scroll-triggered counter animations for key metrics
- **Scroll Reveal Animations** - Smooth entrance animations as content comes into view
- **Sticky Navigation** - Fixed header with active section highlighting

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Vanilla JavaScript (no dependencies)
- Google Fonts (Inter + Playfair Display)

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. No build tools or dependencies required

## Customization

- **Brand colors**: Edit CSS custom properties in `:root` at the top of `css/styles.css`
- **Content**: Update text directly in `index.html`
- **Contact details**: Update phone, email, and address in the contact section
- **Pricing**: Adjust plan names, prices, and features in the pricing section
- **Images**: Replace the placeholder SVG in the About section with your own photo
